# device_apps (vendored)

Vendored copy of [`device_apps` 2.2.0](https://pub.dev/packages/device_apps) with a patched
`android/build.gradle` for Gradle 8+ / AGP 9 compatibility (replaces removed `jcenter()` and
updates the Android library build).

Dart API and plugin sources are unchanged from upstream 2.2.0.
